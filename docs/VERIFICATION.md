# 历史验证摘要

以下是对应开发阶段的结果。当前版本的检查方式见[开发指南](DEVELOPMENT.md)，已确认缺陷见 [Issues](https://github.com/Kylan3320/peak-distance/issues)。

| 范围 | 当时的结果 |
| --- | --- |
| M2–M5 网页查词、收藏、复习与上下文问答 | 验证了从词卡收藏原句并进入复习，以及从页面把材料加入问答。 |
| M6–M7 YouTube | M6 完成字幕和在线服务集成。M7 补齐了人工和自动英文字幕的真实视频观看验证。逐来源的时间对齐和缓存问题按单项核对。 |
| M8 工作区 | 用隔离浏览器验证侧栏和浮动工作区切换及主要学习操作。 |
| M10 与后续问答修复 | 验证了发送消息、移除附加选区、打开历史和恢复工作区。后续查词及问答可靠性修复随 v0.6.7 发布。 |
| M11 学习库 | 当时完成模块检查和受控浏览器检查。后续文件格式和双浏览器同步结果见[学习库规格](specs/vault-collections-sync.md#验证)。 |

本机截图、运行日志和逐次复验记录由维护者在本地归档。
