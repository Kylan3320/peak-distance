# YouTube 词卡与播放交互

布局、字幕设置和收藏见 [PRD](../PRD.md#youtube-学习界面)。字幕范围和逐句暂停单位见[学习句规格](subtitle-sentence-units.md)，跟随与阅读见[字幕阅读](subtitle-reading-fixes.md)。

## 词卡

- 悬停显示就地简明词卡，指针移入词卡时保持打开。点击词语展开同一张卡，再次点击收起。展开后通过点击另一词语切换。词卡绑定原文、轨道、视频和位置。
- 选中文字走选区入口。键盘可打开和关闭词卡，Esc 优先关闭扩展浮层。卡外点击按 [M10](m10-chat-and-popup-interactions.md#4-选区入口与词卡关闭) 处理。

## 暂停与恢复

| 事件 | 播放行为 |
| --- | --- |
| 正在播放时出现悬停词卡 | 由插件暂停，并记录恢复资格 |
| 原本已暂停时出现词卡 | 保持暂停，关闭时不自动播放 |
| 鼠标进入卡片、在词之间切换或展开详情 | 保持当前暂停，不反复播放 / 暂停 |
| 离开悬停卡或关闭详情 | 仅当暂停由本次查词造成、仍是同一视频且没有其它暂停原因时恢复 |
| 用户手动播放 / 暂停、跳转或更换视频 | 撤销原查词恢复资格；手动播放后本次悬停不立即再次暂停 |
| AP 已要求暂停 | 查词卡关闭不得解除 AP 暂停 |


## 逐句暂停

AP 默认关闭。自然播放越过对应播放区间末尾时只暂停一次，主动重播可以再次触发；跳转不补停跳过的区间。以媒体时间判断。关掉 AP 时保留当前播放状态。

## 视频词汇与模式

- 词语页按当前轨道的规范化字幕统计词次，合并大小写等价的词面，同位置只列一次。详情默认使用首次出现的原句，时间按钮单独触发跳转。
- 本视频翻译方式和 AP 跨同标签页刷新与 worker 重启保持，换视频按默认设置初始化。翻译请求携带本视频方式；缺失时拒绝请求。
