# 学习库集合文档与双向同步

本文维护共享学习库的读写行为、文件组织、迁移与兼容。

## 文件组织

```text
学习库/
  生词本.md
  句子.md
  知识点.md
  对话/...
  材料/...
  偏好.md
  .peak-distance/...
```

- 词语、句子、知识点各一份 Markdown，记录按稳定 ID 分节。独立知识点和主动收藏的翻译摘录共用知识点集合。每个会话一份 Markdown。
- 记录受管属性写在 YAML 围栏中；“我的笔记”、自定义属性和小节保留。集合有独立格式标识，不能把分隔标记丢失的正文误判成空库。
- 集合的正文与恢复数据随同一 Markdown 文件提交，包含词典结果、时间、词形、视频位置和知识点删除标记。旧集合首次写入时沿用旧辅助数据并将其纳入文件。
- 旧词语／句子散文件合并后重新读取核对，源文件备份在辅助目录。删除源文件前复读校验；外部改动导致冲突时停止归档，保留源和备份。
- 旧句子的稳定 ID 可恢复视频、轨道和起始位置。准确结束位置、标题和完整释义须由保留这些字段的原浏览器写入。
- 对话文件名使用可读标题和短 ID，去重按记录 ID。整个学习文件夹（含辅助目录）是恢复单位。单篇 Markdown 可独立阅读。
- `.peak-distance` 保存格式版本、关联、必要修订、删除和冲突信息；不增加完整版本历史。

## 混用版本限制

共享同一学习库的浏览器应一起升级。目录格式 `5` 将集合恢复数据并入 Markdown，旧版扩展会拒绝连接已升级的目录。旧格式 `4` 的兼容问题见[当时的记录](https://github.com/Kylan3320/peak-distance/blob/bb703a2/docs/specs/vault-collections-sync.md#混用版本限制)。

## 连接与读回

- 未连接文件夹仍可使用全部学习功能，保持现有本机保存。设置提供“连接学习文件夹”；Chrome／Edge 分别选择同一目录并授权。
- 空目录初始化学习库；已有学习库读取库身份后连接，不覆盖。第一次连接将本机持久记录增量合并进去，重复连接不重复导入。
- 一个浏览器配置文件连接一个学习库。断开不删除文件，待办按库身份保留；连接另一目录时不自动搬入原库内容。
- 目录可以是 Obsidian 仓库中的专用子目录；只管理该范围内已识别的学习文档，忽略 Obsidian 配置、回收站和无关文件。
- 连接后，文件夹承载共享持久资料。运行副本、待办和事务见[技术边界](../ARCHITECTURE.md#多语言与本地学习库边界)。
- 收藏／状态等先事务性提交本机并排队写入。只有共享文件及必要元数据成功提交，才显示“已写入学习库”。未成功时显示“已保存在本机，待写入”。
- 学习库自动读回的触发范围待确认，见[路线图](../ROADMAP.md#待确认的产品决策)。
- 关闭面板后网页收藏、后台完成的聊天也要能写入，或保留可恢复待办并在下一次活动时自动补写。运行上下文见 [ARCHITECTURE](../ARCHITECTURE.md)。
- 同步失败提供重试，缺少权限时在独立设置页为原目录重新授权。更换目录是独立操作。
- 对话和材料解析兼容 BOM、CRLF 和 CR。读取时统一换行，保留磁盘原文件。格式错误可定位到库内相对路径和原因。

## Obsidian 双向编辑

| 外部操作 | 扩展行为 |
| --- | --- |
| 修改词条 `status` 或“我的笔记” | 下次读取更新列表、详情、复习及页面标记；扩展也提供简单笔记编辑入口 |
| 给句子补充个人笔记 | 更新句子时保留文件里的笔记。扩展内只读回受管的句子字段 |
| 给对话补充个人笔记 | 目标是独立保留笔记与历史消息。目前在文末追加笔记可能被解析为最后一条消息的一部分，见 [#17](https://github.com/Kylan3320/peak-distance/issues/17) |
| 给词语／句子添加自定义属性或其它正文 | 更新受管字段时保留这些内容及格式 |
| 会话文件在 `对话/` 内改名或移动 | 按稳定 ID 读回和续写已有文件，成功续写后更新路径索引 |
| 删除记录（集合内分节或独立文档） | 成功读取完整目录并排除同 ID 移动后记录删除；旧缓存不能复活记录 |
| 暂时写坏属性、重复 ID、修改历史消息／材料等受管内容 | 保留文件，定位该项问题；暂停该项写回，其它记录继续工作 |

在 Obsidian 编辑笔记和状态时，保留词条 ID、源语言和表达。状态值沿用 saved／learning／known。

无 ID 的普通笔记不自动导入。

## 合并与并发

合并依据上次共同内容、当前文件和本机修改。

| 变化 | 处理 |
| --- | --- |
| 两边追加不同语境／独立记录 | 合并保留；按稳定标识去重 |
| 一端取消共同快照中的词汇原句 | 删除该原句，保留同词其他原句、笔记和复习选择；另一端的旧原句或迟到释义不会恢复它 |
| 笔记变化＋释义追加，或不同字段变化 | 自动合并 |
| 同一字段改成相同结果 | 视为一致 |
| 同一状态改成不同值，或同段笔记被双方修改 | 报告冲突并保留双方内容 |

整条词汇或收藏句删除与另一端的旧副本修改相撞时，报告冲突并保留可恢复内容和待办。已确认删除后，用户可重新收藏。跨程序写入边界见 [ARCHITECTURE](../ARCHITECTURE.md#多语言与本地学习库边界)。

词形三方合并沿用共同基准。基准已有的词形任一端移除即移除，双方新增取并集；无基准时保留两边值。发布与读回复用同一规则。

## 聊天与材料

共享学习库可同时在两个浏览器使用，写入后通过同步读回。

- 每条历史消息保留角色、文本、次序、时间、完成／停止／失败／中断状态；保留解释标记和现有可用来源信息。材料、引用段落、范围、视频位置与对应轮次共同保存。
- 共享完整的已持久化历史及每轮实际提交的材料范围。
- 对话 Markdown 提供顺序阅读和材料链接。材料快照不可变。删除会话时清理该会话独占的材料，保留其它会话文件。
- 每轮生成归发起浏览器所有。本机按现有机制保存流式进度，文件按适当节奏写入，完成／停止／失败时尽快提交；另一浏览器不自动接管、重试或把外部生成状态改成中断。
- 文件写入尚未完成时，另一浏览器只能看到已写入部分；界面显示同步状态。发起浏览器恢复后按自身请求情况处理中断。
- 共享历史经同步读回。若本机正在生成而延后导入远端会话，保留原共同基准。续问完成后若与远端分叉，同步报告冲突，保留远端文件及本机待办和冲突副本。
- 会话和未发送内容的边界见[会话规格](m10-chat-and-popup-interactions.md#2-会话与临时编辑)。连接和刷新学习库不重建或覆盖当前未发送草稿。

## 迁移

- 在原 IndexedDB 上增量升级；保留原有记录 ID／关联的可追溯映射和旧版本数据。首次写入学习库后重新读取并核对关联，再确认迁移完成，不通过清库简化实现。
- 有明确轨道语言或可核对词典证据的旧记录按证据归属。只有英文产品定位、ASCII 拼写、旧请求固定 en 等不足以证明原文语言；无法确定的放“待确认”，仍可查看／复习，不自动用于跨语言标记。
- 同一旧词条的语境若实际跨语言，按语境拆分并保留旧身份映射。迁移可继承旧状态以避免丢失用户操作，并标明待确认；新发生的跨语言状态互不联动。
- 两浏览器已有数据按语言身份、语境及稳定消息身份合并，重试迁移不增加副本。ID 相同但内容分歧按冲突处理，不把不同会话仅因标题相同就合并。
- 已保存的原文与历史译文保持可读。修改目标语言后保留历史结果。
- 旧版本持久化草稿保留本机兼容数据，不作为共享聊天历史或自动发送。
