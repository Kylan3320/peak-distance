# 整体前端改造：简约默认与经典主题

状态：方案于 2026-11-06 确认，代码已实施并通过本轮验收。交付证据和既有待验项见 [ROADMAP](../ROADMAP.md)。

## 1. 目标与依据

让 Peak Distance 在网页、X、YouTube 和所有扩展界面中呈现克制、成熟、一致的工具感：学习内容更易读，重复信息更少，常用操作易找到，切换外观不中断正在做的事。默认采用用户确认的新风格，经典主题保留旧视觉气质。

本规格维护本轮覆盖范围、技术边界和完成条件；[design.md](../../design.md)是共用布局、主题取值和控件规则的唯一设计来源；[PRD](../PRD.md)维护产品行为。图片提供视觉参考，未画出的现有能力按行为规格保留。历史文档中被替代的视觉要求不再作为本轮验收依据，其数据、播放、会话和来源规则仍有效。

## 3. 必须保持的行为

主题和布局只改变表现及明确规定的控件呈现，不改变学习含义：

- 同形异语、来源范围、学习状态及去重按 [PRD 学习数据](../PRD.md#学习数据)。隐藏逐词语言标签不合并记录；收起域名不丢来源，也不把词典／译文／AI 词义冒充语境解释。
- 收藏、状态修改、笔记、知识点编辑／删除继续调用现有数据入口，保留库归属与迟到结果保护。不同场景的书签行为按 design，不能统一成一种点击效果。
- 问答、材料与未保存草稿的生命周期按 [PRD 问答与材料](../PRD.md#问答与材料)。主题切换不清空输入、不取消生成、不保存空会话。
- 复习范围、独立揭示、队列与返回目标按[文章学习规格](current-content-learning.md#22-本篇复习)。界面简化不删除未揭示时的切题／跳题／打乱能力。
- 视频继续使用现有轨道、字幕片段／学习句、定位、跟随、暂停恢复和 AP。切换主题不重新获取字幕、调度翻译或重建词汇标记。
- 既有查询、授权、服务配置及共享学习库格式保持不变。图稿没有呈现的字段或错误恢复入口继续可达。

## 4. 主题与实现边界

主题产品规则见 [PRD 工作区与设置](../PRD.md#工作区与设置)，视觉差异见 [design](../../design.md#设计方向与主题)。

- 只提供简约／经典，默认简约。新安装和升级后无主题记录均使用简约；明确选择经典才恢复经典。保存为当前浏览器设置，换学习库不改变，主题不写入共享目录。
- 复用现有 Settings 校验、读取、写入及通知链，增加一个主题字段和必要的共用样式应用逻辑。保持 WXT + TypeScript + DOM/CSS；不引入 UI 框架、主题引擎、第三主题、数据库迁移或新权限。
- 两主题共用组件、布局、SVG 和行为，只改变视觉值。先接入共用 tokens／控件，再清理各界面影响主题的写死颜色、纸纹及山景；不为此重写无关模块。
- 扩展页面在自己的根节点应用主题；注入 UI 在自身 Shadow Host／作用域应用。浮动外壳与 iframe 内容一致。网页正文标记只更新扩展自己的样式，不把主题变量或通用样式覆盖到宿主页面。
- 已打开及之后创建的界面均跟随主题。切换保留内容、输入、选区、展开／滚动、复习与播放状态，不额外抢走当前操作的焦点；复用设置通知时避免纯主题变化进入内容重载／翻译分支。
- 首次显示复用已知主题；尚未读到设置时允许简约基础样式，再应用保存值。不为消除短暂色差阻塞词卡原文、拖动、关闭或整个工作区启动，不增加全局加载遮罩、轮询或自动重载。
- 普通设置保存规则沿用既有实现；主题保存失败就近反馈，不宣称已保存。不得把旧的显示语言、理解语言或服务配置顺带覆盖。
- 单工程、活动主面板唯一、扩展源凭据隔离和状态移交边界继续按 [ARCHITECTURE](../ARCHITECTURE.md)。后台只作主题设置所需的最小改动。

## 5. 实施顺序与决策边界

1. 完成共用主题、控件语义及外壳，落实 design 中的导航、工具、提示、菜单和排版。
2. 将共用规则应用到第 2 节全部界面；优先贯通文章 → 学习库 → 复习，再接问答／设置、就地浮层及视频。
3. 核对覆盖范围与下述用户结果，修复本轮引入的问题，同步进度并按 AGENTS.md 完成 Git 收尾。

默认复用当前检出目录。执行者自行处理局部函数和 CSS 组织；不重新决定主题数量、默认值、导航、信息隐藏规则或业务流程。只有现有有效行为与本规格发生无法兼容的实质冲突，或必须扩展范围才能继续时询问用户，其他部分继续推进。不要求固定 agent 数量、逐页审批或另写过程报告；如分工，共用契约确定后再划分文件归属。

本轮不升级版本、不发布、不更新用户已安装的插件。ROADMAP 已列出的非本轮缺陷不顺手纳入重构；若影响必要验证，注明具体受阻结果，保留待验状态。

## 6. 验收标准：以使用结果为准

测试命令和截图是证据手段，不是产品完成条件。不得为通过旧选择器、截图或测试次数删功能、改含义、弱化错误与状态保护。

| 用户需要 | 完成时必须成立 |
| --- | --- |
| 随处获得同一种新体验 | 第 2 节所有可见界面都采用共用规则；简约中无残留山景、纸纹、品牌口号、逐词语言标签和常驻图标说明；design 中明确的字段、来源及危险确认等文字例外完整保留 |
| 内容更易读、操作仍可发现 | 主内容先于辅助信息；列表详情按需展开，状态、来源、筛选、编辑和恢复入口可找到；图标可通过悬停／键盘提示识别，功能没有因图稿省略而消失 |
| 默认正确且主题可换 | 无主题记录时使用简约；主动选择经典后重开仍保持；两种主题覆盖所有承载界面，经典没有恢复另一套旧布局，宿主网页未被换肤 |
| 学习可以连续完成 | 选词 → 收藏 → 查阅原句与笔记 → 复习 → 返回来源可完成；翻译摘录仍保存为独立知识点并可回到来源；状态、语言、来源与保存内容正确，字幕定位及 AP 不因新控件退化 |
| 操作过程中可换主题 | 未保存输入、材料、AI 配置草稿、展开／滚动、文本选区、复习揭示／进度及视频播放意图保持；切换本身没有新的查词、翻译或 AI 请求 |
| 窄栏与失败状态仍能用 | 长词／长值在窄栏和缩放下可读可操作，无横向溢出或关键控件遮挡；失败保留原文／输入并有真实恢复入口；新增文案覆盖现有五语言 |

### 最小必要验证

- 对最终差异做类型与构建检查；新增文案核对五语言目录。复用相关现有检查，只补尚不能证明上述用户结果的缺口，不运行与改动无关的全量可靠性或发布验证。
- 正常态逐类浏览第 2 节。共用布局以 320／400／600 CSS px 检查，用窄栏的长词、长设置值与德语验证最容易挤压的状态，并检查一次 125% 缩放。正文／焦点对比及键盘提示检查共用样式即可；播放器另看亮／暗画面。
- 用少量样例贯通三条链路：①网页选词、收藏、笔记、文章／全局查阅、独立揭示复习与返回；②问答附材料、生成／停止、标记／保存知识点，以及一处可恢复的保存失败；③视频选区、查词、句子收藏、定位、跟随与 AP。就地翻译确认原文、收藏与来源入口；句子列表确认取消收藏，知识点列表确认编辑／删除，不只浏览词语页。
- 在这些链路中顺带切主题：分别检查未保存草稿／配置、文本选区、复习进度和播放状态；再重开界面验证保存选择及不同承载的一致性。无需对每条链路遍历所有主题、语言和尺寸组合。
- 在实际原生侧栏、浮动面板和视频全屏中各确认关键操作可用，独立设置页及翻译准备页能使用新主题。受控数据可以验证 UI；原生承载／播放结果不能用静态截图冒充。已有同一构建的有效证据可复用，浏览器特定承载检查覆盖 Chrome / Edge，不重复全部业务链路。
- 更新与新目标冲突的旧视觉断言，例如欢迎打字、文字状态下拉和固定品牌栏；保留来源、草稿、收藏及播放行为断言。不为可逆的间距或配色新增镜像实现的单元测试。
- 保留能说明结果的代表截图及失败／修复证据即可，不要求逐状态截图包、重复全套检查或固定测试次数。无新改动、失败或疑点时结束验证。

交付简述实际改动、验收证据、仍受阻的具体结果及提交位置。所有目标已实现且必要结果有证据后才标记本轮完成；环境未能验证的项明确待验，不以脚本通过代替。
