会话与临时编辑见第 2 节，卡外关闭见第 4 节。当前产品行为见 [PRD](../PRD.md)，控件呈现见 [design.md](../../design.md)。阶段结果见 [M10 报告](m10-verification-report.md)。

## 2. 会话与临时编辑

### 保存边界

- 打开 AI 问答、点击新对话、输入文字、附加材料或带入引用，都不创建持久化会话。界面可显示“新对话”和输入框，无会话 ID 是正常状态。
- 首次发送通过问题长度、配置等现有前置校验后，将会话、首条用户消息、所用材料／引用及回答占位一起提交；不先落一个空壳。本地提交成功后才清空输入并启动生成。
- 前置校验或本地提交失败：保留临时内容，不新增历史。已提交后的网络失败、停止或中断：保留已发送问题及相应状态，沿用重试入口。
- 后续输入和尚未发送的材料／引用修改同样属于临时编辑；历史消息绑定的材料快照不变。发送成功后，新材料成为该会话已提交的上下文。
- 活动会话读取不自动创建记录；旧 ID 已删除时返回空态。空态、请求失败分开处理，读取失败不能覆盖当前输入。

### 用户确认的“离开”边界

| 操作 | 未发送内容 |
| --- | --- |
| 新建对话、成功切换到另一会话 | 丢弃当前临时输入、材料与引用修改；切换失败仍保留 |
| 明确关闭面板、关闭承载页面／窗口、重新加载扩展 | 丢弃；重新打开不恢复未发送内容 |
| 切换生词本、复习、设置等模块 | 保留临时内容 |
| 切换浏览器标签页 | 保留临时内容 |
| 固定／浮动模式切换，以及全屏容器移交 | 保留临时内容；切换失败保留原容器内容 |
| 仅打开／关闭历史列表 | 保留临时内容 |

临时内容与已提交内容必须分开：离开已有会话只丢弃本轮未发送修改，返回时仍可使用最后已提交的材料。新会话丢弃后回到空态。不增加“是否保存草稿”弹窗或草稿历史页。

实现可复用窗口级工作区临时状态及现有模式移交机制；不写入会话库或永久存储。若使用 `storage.session` 移交，显式关闭后清除，重新打开不能当作可恢复草稿。不要仅凭 `visibilitychange` 或连接断开判定用户关闭：标签切换和模式切换也会触发这些事件。

### 删除与清空

- 删除非当前会话：当前内容不变。删除当前会话：保留历史列表及滚动位置，当前内容回到未保存的新对话空态；没有剩余会话时显示历史空态。
- 删除成功才移除列表行和清除活动 ID。失败保留原对象并在该行提示，可再次操作。删除生成中的会话沿用现有取消路径，迟到结果不能写回。
- 新建／切换／删除时失效旧的读取及临时编辑回写；复用操作身份检查，不引入通用任务调度或全局锁。
- 清空仍清除当前消息和材料，不影响生词本；清空后的纯空白不继续作为新历史条目保存。未保存空态的清空不发数据库请求。
- 旧版本记录不做自动批量删除；已有零问记录仍可逐条删除，不能仅按问题数误删带材料或草稿的旧数据。旧版本持久化草稿的批量迁移另行处理。

## 3. 删除确认

列表行和当前对话使用同一确认组件，确认对象绑定会话 ID。展开后可确认或取消，失败保留记录并恢复操作；删除不改变词汇、句子和独立知识点。控件结构、尺寸、动效及主题由 [design.md](../../design.md#工作区与通用操作) 维护，原组件及许可状态见 [REFERENCES](../REFERENCES.md#m10-删除交互移植)。

## 4. 选区入口与词卡关闭

- 查词／翻译共用单层选区操作条，动作名称、命中区与焦点样式见 [design.md](../../design.md#网页与视频中的界面)。
- 词卡打开时隐藏相应选区入口；旧选区和延迟的选区事件不能立即把入口重新显示出来。新选区可以正常触发下一次查询，不用清除原文选区来掩盖问题。
- 完整词卡与字幕紧凑词卡都支持外部点击关闭，不依赖定位锚点。点击同时继续执行所点网页操作；不覆盖透明遮罩、不吞掉点击、不在外部关闭后强行恢复旧焦点。
- 卡内选字、切词典、保存、展开义项和拖动不误关。拖动始于卡内、结束于卡外不当作一次外部点击。点击另一个词时直接切换到新词，旧关闭事件不能关掉新词卡。
- 保留显式关闭和 Esc。外部关闭复用已有取消请求／`onClose`，迟到结果不重开卡片，YouTube 暂停／恢复沿用原约定。
- 点击范围覆盖网页正文和扩展自己的工作区；跨自有 iframe 使用现有扩展通信传递关闭意图，不读取 iframe 内文档，不建立通用页面消息代理。该规则关闭的是词卡，不是主工作区。
- 同类选区翻译卡同步采用外部点击关闭。点击监听限普通页面与自有工作区，边界外的第三方 iframe 和浏览器地址栏沿用浏览器行为。
