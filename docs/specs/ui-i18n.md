# Peak Distance 界面规范

本文维护界面语言、设置与控件状态规则；交付与检查状态见 [ROADMAP](../ROADMAP.md)。文案及设置分组沿用 2026-10-12 确认的方案。

## 设置分组

- 按用户任务整理设置，保持已有纸纹、海岸插画、配色和控件样式。
- 设置依次为语言、查词、字幕、文件共享、AI 服务；低频项按需展开。

## 文案

命名、动作语义与长度约定维护在 [文案约定](../ui-copy.md)；具体五语言字符串只在 [shared/uiMessages.ts](../../shared/uiMessages.ts) 维护。

## 语言

- 显示语言支持跟随浏览器、简体中文、繁體中文、English、Deutsch、Français。
- AI 问答读取发送时生效的显示语言；解释语言独立控制查词解释与译文。
- 浏览器语言不受支持时使用英文。
- 显示语言保存在当前浏览器，不写入共享学习文件夹。
- 只翻译带文案标记的界面节点；网页原文、笔记、材料、问题和历史回答保持原样。
- 切换语言更新现有节点，不刷新页面或重建表单。

## 控件与状态

- 设置中的语言规则编辑器初始不预选原文语言，规则内原文与解释语言不能相同；规则使用主语言标签保存。选区翻译卡的语言控件按[翻译学习规格](translation-learning.md)执行。
- 单选下拉在设置、侧栏及网页／视频 Shadow DOM 中共用可定制的原生 picker，视觉规则见 [design.md](../../design.md)；保留原生选值与键盘行为。图标操作具有当前显示语言的提示、可访问名称及对应状态，菜单选项与字段名使用文字；笔记编辑的保存／取消使用 SVG，保留本地化提示与可访问名称。
- 帮助文字只解释必要的作用、范围或费用，文件格式与技术配置按需展开。
- 开关标签、说明和操作结果使用当前显示语言。设置说明归入对应字段，普通设置保存结果显示在该字段附近；成功短暂显示、失败保留输入与错误，空反馈区不占位。AI 配置仍需明确保存，切换显示语言不丢未保存草稿。
- 保留输入、选项、展开状态、音视频播放与滚动位置；语言切换不发起 AI 请求。
- 窄栏与视频菜单中的选择框单独成行，完整显示所选语言；开关仍与标签同行。
- AI 配置区分未设置、未保存和已设置；当前服务与模型只取已保存配置，正常已配置时不重复显示静态成功文字。密钥清除、保存启用和面板顶部操作使用 SVG，保留本地化提示及可访问名称；文件共享操作同样提供提示，连接状态、同步数量／时间与错误分别显示；缺少权限时提示重新连接。
- 展开设置使用 160ms 淡入位移；减少动态效果时停用。已有删除确认动画沿用。

## 验证

- `npm run check-i18n`：语言匹配、目录完整性、AI 提示、数据与控件状态保持。
- `npm run check-ui-i18n`：默认读取 `.output/chrome-mv3-dev`，需先运行 WXT 开发服务并安装 Playwright Chromium；生产产物先构建，再用 `PEAK_DISTANCE_UI_EXTENSION=.output/chrome-mv3 npm run check-ui-i18n`。隔离浏览器验证保存、读回、错误与实际 AI 请求参数，AI 返回使用测试数据。
