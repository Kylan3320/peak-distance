## 语言

- 显示语言支持跟随浏览器、简体中文、繁體中文、English、Deutsch、Français。（用户确认）
- AI 问答读取发送时生效的显示语言；解释语言独立控制查词解释与译文。（用户确认）
- 浏览器语言不受支持时使用英文。（Agent 推断）
- 显示语言保存在当前浏览器，不写入共享学习文件夹。（Agent 推断）
- 只翻译带文案标记的界面节点；网页原文、笔记、材料、问题和历史回答保持原样。（Agent 推断，落实功能不改）
- 切换语言更新现有节点，不刷新页面或重建表单。（Agent 推断）

## 控件与状态

- 原文语言初始不预选，原文与解释语言不能相同；规则使用主语言标签保存。（Agent 推断）
- 帮助文字只解释必要的作用、范围或费用，文件格式与技术配置按需展开。（用户确认方案 B）
- 开关标签、说明和操作结果使用当前显示语言，错误显示在相关操作附近。（Agent 推断）
- 保留输入、选项、展开状态、音视频播放与滚动位置；语言切换不发起 AI 请求。（Agent 推断）
- 窄栏与视频菜单中的选择框单独成行，完整显示所选语言；开关仍与标签同行。（Agent 推断，经实际外文评审调整）
- AI 配置区分未设置、未保存和已设置；当前服务只取已保存配置。（Agent 推断）
- 展开设置使用 160ms 淡入位移；减少动态效果时停用。已有删除确认动画沿用。（Agent 推断）

## 验证

- `npm run check-ui-i18n`：默认读取 `.output/chrome-mv3-dev`，需先运行 WXT 开发服务并安装 Playwright Chromium；生产产物先构建，再用 `PEAK_DISTANCE_UI_EXTENSION=.output/chrome-mv3 npm run check-ui-i18n`。隔离浏览器验证保存、读回、错误与实际 AI 请求参数，AI 返回使用测试数据。
