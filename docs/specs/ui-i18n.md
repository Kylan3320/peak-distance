# 界面语言与文案

设置分组和控件见[设计规范](../DESIGN.md)。

## 语言

- 界面语言支持跟随浏览器、简体中文、繁體中文、English、Deutsch、Français。
- AI 问答读取发送时生效的界面语言，用户指定回答语言时优先采用。翻译与释义语言独立设置。
- 浏览器语言不受支持时使用英文。
- 显示语言保存在当前浏览器，不写入共享学习文件夹。
- 切换语言时原位更新界面，保留网页原文、笔记、材料、问题和历史回答。

## 控件与状态

原文与译文分别处理文字方向和字体回退，RTL 原文局部排版，中文界面保持从左到右。

- 设置语言区呈现「界面语言」和「翻译与释义语言」。选区翻译卡的原文语言和目标语言只作用于本次查询。见[翻译学习规格](translation-learning.md#4-请求语言与响应)。
- 图标操作的提示、可访问名称与状态跟随显示语言；提示在悬停及键盘聚焦时可见。学习状态和语言筛选的名称包含当前状态／范围，图标不带常驻说明文字。
- 开关标签、提示和操作结果使用当前显示语言。切换显示语言保留未保存的 AI 配置草稿。
- 播放器译文收束仅裁剪当前单位的可见行，辅助技术可读该单位全部译文。字幕页按钮关闭时提示「显示完整译文」，开启时提示「显示逐行译文」，同步本地化 title 与可访问名称。aria-pressed 表示用户选择，aria-busy 表示还在取得所需结果；失败就近提示。
- 保留输入、选项、展开状态、音视频播放与滚动位置；语言切换不发起 AI 请求。
- 当前服务与模型取已保存配置。文件共享的连接、同步和错误状态使用当前显示语言。

## 文案

界面标签、提示、错误和各语言译文维护在 [shared/uiMessages.ts](../../shared/uiMessages.ts)。扩展清单文案维护在 [public/_locales](../../public/_locales)。

- 同一功能在侧栏、网页和视频中使用同一名称。功能名尽量简短，动作写清结果。说明放在相关字段或动作旁，写明输入范围、状态、结果或恢复步骤。
- 「标记回答」只标记聊天内回答，「保存知识点」产生独立学习记录，「收藏翻译」保存选区摘录。删除会话、清空消息、移除材料与取消焦点分别表达各自的结果。
- 图标提示和可访问名称写明动作与当前状态。例如「只看本对话已标记回答」包含筛选范围。菜单、字段、来源、必要结果与危险确认使用可见文字。
- 外观选项统一称「外观主题」「简约」「经典」。按实际目标命名原文来源与词典原页，分别标明词典、普通译文、AI 词义和原句解释。
- 生成、停止及失败状态就近反馈。失败说明原因和可执行动作，成功反馈一次即可。
