# 字幕获取、阅读与收藏

本文维护字幕获取、跟随、选区与收藏反馈。断句、定位及译文归属见[侧栏学习句规格](subtitle-sentence-units.md)，待实机条件见 [ROADMAP](../ROADMAP.md#待实机验证)。

## 1. 获取生命周期

沿用30秒整轮期限，不因失败、来源更新或已有自动唤醒延长。候选URL不等于成功来源；非空可解析字幕才成功。空正文、单次超时、网络／解析失败记录原因并等待本轮新来源，不立即 failAcquisition/source-cancel。同一候选URL的重复捕获不重复拉取失败请求；URL更新或用户显式重试可再请求，复用现有标识，不建重试队列。保留现有一次唤醒，不增加周期重试。

成功、整轮超时、关闭字幕、切视频／轨道按现有代次收尾；旧响应不得恢复。保留请求参数，不把必须含pot作为通用成功条件。最终提示区分空响应／网络／解析／超时，诊断不包含完整URL或凭据。保留现有获取方式，不扩展响应截取或备用源。

## 2. 侧栏整句与播放器短片段

侧栏显示学习句，播放器显示短片段。两种表示的来源映射、译文、收藏身份与 AP 边界以[侧栏学习句规格](subtitle-sentence-units.md)为准。

## 3. 收藏反馈

词卡书签切换当前原句的收藏，字幕行书签切换整句收藏。保存和取消均等待本机写入回执，提交期间阻止重复操作，失败后恢复按钮并就近提示。学习库同步独立反馈。保存成功时书签原位切为实心并显示一次反馈，遵循减少动态效果偏好。轮询、译文回填和重渲染不重播动效。视频收藏分类见 [PRD](../PRD.md#youtube-学习界面)，控件样式见[设计规范](../../design.md)。

## 4. 阅读、跟随、气泡

字幕原文DOM只在视频／轨道／字幕内容变化时重建；收藏、状态、译文局部更新。收藏不seek、不主动滚动、不清选区、不改变跟随意图。

跟随意图只有自动／手动：用户真实滚动转手动；创建选区临时暂停，不改意图；选区清除时自动意图立即跟随当前项，手动意图保留位置。回到当前句清除字幕选区和气泡、恢复自动并定位。普通点击不改变跟随意图。快照只存已有跟随意图及位置，不存临时选区状态。

播放器与侧栏字幕气泡：选区空、外点、Escape、离开视图／视频／轨道、选区节点失效即关闭；内点保留选区直到读取固定文本及来源；外点不吞操作、不抢焦点；主动关闭后同一未变选区不立即重开；销毁清监听。查词卡与翻译卡仍按各自生命周期，翻译卡保持展开不变。
