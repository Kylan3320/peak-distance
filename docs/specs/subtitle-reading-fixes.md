# 字幕获取、阅读交互与收藏修复

2026-10-29：用户批准实施；本文是本批次执行规格。状态和入口由 ROADMAP 维护。未发布，不改版号。

## 事实与范围

- 已复现：收藏触发列表重建，译文回填前恢复 scrollTop 导致位置截短；任意 pointerdown 关闭跟随，选区结束不恢复；侧栏选区失效时未清理气泡。
- 已确认：学习库材料的 CRLF 被只接受 LF 的解析器拒绝，内存统一换行即可读取；对话解析器有同类入口。
- 已实测：失败的原生／扩展字幕请求返回 200 空正文；卸载后重新开关原生 CC，携带 pot 的原生请求返回 1,242 条字幕。凭据最初缺失的成因未证实。
- 已受控复现：首次空响应导致 source-cancel，随后有效来源不能产出字幕，重开获取后成功。这是本轮获取修复对象，不承诺解决所有平台空响应。
- 不增加渠道、AI 断句、同步引擎、数据库迁移、通用状态框架或长期监控；保留现有五语言、存储、请求代次和视觉体系。

## 1. 获取生命周期

沿用30秒整轮期限，不因失败、来源更新或已有自动唤醒延长。候选URL不等于成功来源；非空可解析字幕才成功。空正文、单次超时、网络／解析失败记录原因并等待本轮新来源，不立即 failAcquisition/source-cancel。同一候选URL的重复捕获不重复拉取失败请求；URL更新或用户显式重试可再请求，复用现有标识，不建重试队列。保留现有一次唤醒，不增加周期重试。

成功、整轮超时、关闭字幕、切视频／轨道按现有代次收尾；旧响应不得恢复。保留请求参数，不把必须含pot作为通用成功条件。最终提示区分空响应／网络／解析／超时，诊断不包含完整URL或凭据。保留现有获取方式，不扩展响应截取或备用源。

## 2. 侧栏整句与播放器短片段

2026-10-29 用户复验后修订：完整句子仅用于侧栏，播放器恢复短片段。MAIN将原始cue经现有ASR去重生成播放器片段，再保守合并成学习句，并保留片段所属学习句映射；content不再重复分组。侧栏、侧栏收藏／查词、前后句／重播、AP仍使用学习句索引。播放器原文和译文按片段切换，同一学习句内的片段变化也重绘。AP仍在学习句末暂停，暂停时保留该句最后相关片段。

- 人工与ASR都合并；只合并完整相邻cue，不拆cue、不猜子句时间、不改写文本。
- 按轨道语言使用Intl.Segmenter句界，并要求实际句末标点；输入结束不算句末。排除小数内部、首字母缩写内部和固定英语称谓Mr./Mrs./Ms./Dr./Prof./Sr./Jr.后的点号边界；不建词典或句法系统。
- 不跨超过1500ms的源字幕时间空隙；遇空隙或轨道末尾，尚无确认句末的候选按原cue输出。无标点不猜句，不调用AI。
- 中文／日文片段间不额外加空格，其他语言加一个空格；保留字符、标点、大小写。合并项起点为首cue，终点为成员最大结束时间。单cue多句不拆，一个显示项可含多句。长句自然换行，不设字数硬切。
- MAIN保存原始cue、去重片段与学习句，分组只运行一次。平台译文用同次获取结果分别对齐学习句和片段；不能在每个短片段下重复整句译文，无法可靠对应的片段走现有已授权翻译路径，不机械裁切译文。普通／AI翻译复用同一调度与取消代次，组和片段请求ID明确分域，相同内容尽量复用，不新增渠道或AI授权。
- 播放器选词／选区固定可见片段文本和时间，侧栏动作固定学习句索引；不得混用两种索引。侧栏消息合同保留原学习句语义。
- 平台缓存包含本次表示版本，并区分学习句／片段。同轨道任一表示的start/dur/text或映射确实改变才清理旧译文索引及在途结果；重复捕获同内容不清理。
- 旧收藏内容、ID、时间保持不变；新整句沿用sentenceId。旧时间链接仍能定位，不用新索引改写历史。
- 保存的源跨度与实际显示边界分离：若下一显示项在该跨度结束前开始，播放显示沿用现有后项优先规则，AP沿用cueEnd裁剪到下一项起点，避免先显示后句又回跳暂停在前句。

## 3. 图标和收藏

SVG范围：词卡保存／已掌握／继续问／关闭；字幕顶部上一句／重播／下一句／回到当前句；字幕行收藏／问AI；本视频已收藏页全部词语／全部句子／复习／取消收藏；全部句子页取消收藏。时间、来源、页签、学习状态下拉保留文字。命中区34px、图形18–20px、现有线性风格、本地化title/aria-label及焦点样式。

收藏：空心书签 → 忙碌且阻止重复提交 → 实际成功后蓝色实心书签及一次160ms动效；失败恢复可操作并就近报错。减少动态偏好只切图形。移除词卡底部绿色成功文字。词卡已收藏以当前语境存在为准，成功按钮不增加取消或导航；字幕保持toggle语义。轮询、译文回填和重渲染不重播动效。视频save动作必须等待实际保存／删除再回执。本机保存和文件夹同步不能混为一谈。

## 4. 阅读、跟随、气泡

字幕原文DOM只在视频／轨道／字幕内容变化时重建；收藏、状态、译文局部更新。收藏不seek、不主动滚动、不清选区、不改变跟随意图。

跟随意图只有自动／手动：用户真实滚动转手动；创建选区临时暂停，不改意图；选区清除时自动意图立即跟随当前项，手动意图保留位置。回到当前句清除字幕选区和气泡、恢复自动并定位。删除任意pointerdown都停跟随的逻辑。快照只存已有跟随意图及位置，不存临时选区状态。

播放器与侧栏字幕气泡：选区空、外点、Escape、离开视图／视频／轨道、选区节点失效即关闭；内点保留选区直到读取固定文本及来源；外点不吞操作、不抢焦点；主动关闭后同一未变选区不立即重开；销毁清监听。查词卡与翻译卡仍按各自生命周期，翻译卡保持展开不变。
