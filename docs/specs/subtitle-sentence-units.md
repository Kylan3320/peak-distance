# 侧栏学习句：本地断句与来源定位

侧栏学习句、来源映射和译文对齐以本文为准。获取、跟随和阅读交互见[字幕阅读](subtitle-reading-fixes.md)。

## 1. 目标与范围

侧栏每项显示一个可由原文句界确认的自然句子，收藏、查词、问答与译文绑定该项。句子可包含从句、依赖上下文或以 And／But 开头；不为补足上下文合并多句，不按长度截断长句。

人工与自动字幕使用同一套本地断句、来源与时间映射规则。播放器显示短片段。

- 断句在本地完成。缺标点或本地无法确认句界时保留原片段。AI 翻译模式不参与断句。
- 无句内时间时，句子分别显示，回放沿用来源片段的定位精度，AP 只在可定位边界暂停。
- 前端不增加解释上述机制的文案、徽标、提示或设置。
- 时间锚点取自已有字幕，不采集音频进行对齐。

## 2. 原文与句界

1. MAIN 保留源片段的文字、已有词段时间和显式换人边界。ASR 去重后建立连续原文及来源对应关系，同时派生播放器片段和侧栏学习项；content 与侧栏不再次断句。
2. 保留现有空白规范化及语言间连接规则。只去除有滚动更新依据的重复；真实口头重复、词序、大小写和标点保持原样，不补词、润色或纠正识别结果。
3. 按轨道语言使用 `Intl.Segmenter` 提取连续原文中的全部句界，允许句界落在源片段内部。用 Unicode `Sentence_Terminal` 属性确认真实句末，允许其后的闭引号／括号；不得用英中日标点白名单排除其他语言的有效句界。保留现有称谓、小数和首字母缩写的误切排除规则。文本结束本身不是确认依据。
4. 字幕分包、换行和时间空隙不作为句界。不跨显式换人边界合句。
5. 每个确认的句子单独输出。换人或轨道结束处仍无确认句末的剩余区间，按其与原片段的交集输出；已经归入完整句子的文字不得再次出现在回退项中。
6. 同一连续原文、语言和换人边界下，可确认句子的文字与顺序不受字幕分包位置影响。未确认区间按第 5 条保留片段。所有学习项按顺序连接后，应还原规范化、去重后的原文。
7. 同一轨道内容一次生成一份结果；播放推进、翻译方式切换、译文回填及收藏不能改变断句。

## 3. 来源、时间与操作

- 每个学习项保留连续原文范围和对应源片段范围。支持一片段含多句、一句跨多片段，文字归属按原文范围确定。
- 时间采用已有词段／片段锚点。句子在源片段内部切开时，以后句首词段的有效起点作为切换及 AP 边界；没有该锚点时不按字数均分时间。句末位于源片段末尾时，使用该片段结束时间，并裁剪到下一可定位项的起点；轨道末项使用其末源片段结束时间。
- 相邻学习项之间没有可区分的时间锚点时，共用一个播放定位区间，但保留独立文本、译文和收藏。点击／重播定位到该区间起点；上一句／下一句仍逐项移动，相同区间内不跳过中间项。
- 自动跟随进入共用区间时定位第一项，区间内不重复滚动；用户显式定位某项后保留该项，直到离开区间或执行新的定位动作。AP 在区间末暂停一次，保留对应的最后播放器片段；不得因多项起点相同产生零时长、连续暂停或回跳。
- 侧栏查词、收藏、问答及选区使用实际所见学习项的文字与来源；播放器操作使用可见短片段。跨项选区按实际选中文字生成材料，不漏字或重复。
- 行操作固定所属视频、轨道及学习项身份／文本，沿用现有内容代次拒绝过期操作；不只凭数组下标执行。内容变化前发出的旧操作不能落到新行。
- 同内容重复获取保留列表身份；译文和收藏只局部更新，保留滚动、跟随意图与选区。断句规则变化不改写旧收藏及已提交问答材料。
- 新学习句收藏 ID 在现有 `sentenceId` 组成项后追加原文范围 `[from, to]`，使共享时间、文字相同但来源位置不同的两句保持独立。范围来自 MAIN 已有连续原文坐标；前端收藏状态、后台写入、删除及重新载入共用这一身份。重复保存同一项不新增；不能通过改写原文、制造时间偏移或随机 ID 区分句子。
- 持久化 ID 在学习库往返时原样保留，不新增数据库迁移，不改变词汇语境的去重规则。旧格式 ID 保留；旧收藏的轨道、起点、文字仅匹配一个当前项时才关联其收藏状态，否则只保留在已保存列表中，不把一条旧记录关联到多个新项。操作已有记录时使用其实际 ID。

## 4. 译文

1. 侧栏以最终学习项全文为翻译输入，结果按该项关联。保留现有批量请求、模式授权、取消与缓存机制，不新增翻译上下文协议。
2. 当前播放区间内的全部学习项都进入翻译候选，保留原有相邻预取窗口；不能只按该区间第一项计算前后窗口。当前播放器片段和显式选择项优先，其余候选按原批次上限接续，直到取得译文、明确失败或所属视频／轨道／语言／模式变更取消。区间内不点击行也应补齐译文；进入下一播放区间不丢弃已纳入但尚未尝试的候选。复用现有调度，不增加全文预翻译或持久任务队列。
3. 平台译文仅在同源翻译结果与完整学习项有明确对应时复用：译文事件与源事件起止一致，源事件完整属于该项；合并项允许拼接全部成员的对应译文。源事件被拆到多项、对应缺失或重复时，整项交给当前已选翻译渠道；独立语言轨道仅有时间重叠的结果不用于侧栏配句。
4. 不按字数或标点机械裁切译文，不将跨句译文重复贴到多项。播放器译文保留既有片段路径。
5. 平台译文缓存区分学习项与播放器片段。断句或来源映射变化时使对应旧索引、在途结果和缓存失效，复用现有代次处理迟到响应。翻译失败不影响原文、定位和收藏。

## 6. 行为用例

句界、来源与播放区间使用 `tools/subtitle-sentence-check.ts`，已包含于 `npm run regress`。按修改范围选择入口。

| 用例 | 通过条件 |
| --- | --- |
| 同文不同分包 | 下方样例分别作为单片段、逐句片段、句中切开的片段，均得到所列三句，字符顺序与口头重复不变 |
| 跨片段与语言边界 | `When the rain` 与 `stopped, we left.` 间隔超过 1500ms 仍为一句；保留现有称谓／小数／缩写及中日文用例，完整句不被误切 |
| 非英中日句末 | `كيف حالك؟ أنا بخير.` 与 `यह पहला वाक्य है। यह दूसरा वाक्य है।` 各按现有标点拆成两句，原文不改写 |
| 回退与换人 | `First sentence. Unfinished`、`tail` 输出 `First sentence.`、`Unfinished`、`tail`；无标点保持原片段；显式换人阻止跨人合并，文字无重复或丢失 |
| 时间映射 | 同一片段内两句分别有／无句内时间：有时间按句推进和暂停；无时间按共用区间处理，逐项导航可达、AP 仅停一次，无零时长 |
| 译文归属 | 同源完整对应可复用；一条译文跨两句或仅时间重叠时，两句均通过现有渠道取得各自译文；迟到旧结果不覆盖新内容 |
| 共用区间译文 | 一个无句内锚点片段含八句，翻译服务正常；不点击任何行即可取得八句各自译文，播放器当前片段也能及时取得译文；请求跨批次／跨播放区间时未尝试项仍能完成 |
| 独立收藏 | 同一无锚点片段 `No. No.` 拆成两行：依次收藏后保留两条记录，刷新后两行均已收藏，取消第二行只删除第二条；同一行重复保存不新增。新旧 ID 经现有学习库格式往返保持原样，唯一匹配的旧收藏仍可取消 |

同文不同分包的固定期望：

```text
But I I sometimes think our society gets too binary.
Everything's either black or white.
Everything gets polarized because of that.
```

打包扩展入口 `node tools/subtitle-reading-check.mjs --packaged-only` 覆盖侧栏与播放器、收藏、换轨及实际消息和存储。翻译使用受控响应，学习数据使用隔离库。
