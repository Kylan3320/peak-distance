# 侧栏学习句：本地断句与来源定位

侧栏学习句、来源映射和译文对齐以本文为准。获取、跟随和阅读交互见[字幕阅读](subtitle-reading-fixes.md)。

## 1. 原文与句界

播放器和侧栏共用一份有序学习句。每项对应轨道中连续的原文和已有的回放时间。操作与翻译方式切换均沿用这份划分。

- 规范化空白，按轨道语言连接片段。自动字幕仅去除有滚动更新依据的重复；口头重复、词序、大小写和标点保留。
- 用轨道语言的句界规则识别已有终止标点，保留闭引号及称谓、数字、首字母缩写的处理。一个源片段可以含多句，一个学习句也可以跨多个片段。
- 英文缺标点的口语结合上下文在本机预测切点，取回的是原文位置。模型生成的大小写和标点不写回原文。显式换人和声音提示保留独立边界；有独立含义的短回答可单独成项。模型不可用或预测内容与原词无法对应时，暂时保留受影响区间的原文、暂停该区间的送译。播放器和侧栏均可重新读取同一轨道。
- 英文自动字幕中的长句，在送译前用标点预测和前后文识别可独立理解的分句。紧密的因果、否定、主谓和插入语保留完整语境。播放器逐项呈现并限制行宽，侧栏保留全文；其它语言沿用本地语言分句。

## 2. 来源、时间与操作

- 每个学习项保留连续原文范围和对应源片段范围。支持一片段含多句、一句跨多片段，文字归属按原文范围确定。
- 时间采用已有词段／片段锚点。句子在源片段内部切开时，以后句首词段的有效起点作为切换及 AP 边界；缺少该词的时间时，定位到它所在源片段的起点；同一片段内无法区分的起点共用定位区间。句末位于源片段末尾时，使用该片段结束时间，并裁剪到下一可定位项的起点；轨道末项使用其末源片段结束时间。
- 多项共用源区间时，按已有词段／片段时间，在相邻时间锚之间依原文位置估算上屏进度，每次显示当前一项。侧栏自动跟随当前项，点击或重播定位到该项的显示起点。近似时间仅用于播放，不写入收藏身份或原始字幕时间。
- AP 只在真实定位区间末暂停一次，保留刚播到的学习项。切换字幕屏不产生额外暂停。手动滚动侧栏仍可独立阅读。
- 侧栏查词、收藏、问答及选区使用实际所见学习项的文字与来源，播放器与侧栏的原句操作使用同一来源。跨项选区按实际选中文字生成材料，不漏字或重复。
- 行操作固定所属视频、轨道及学习项身份／文本，沿用现有内容代次拒绝过期操作；不只凭数组下标执行。内容变化前发出的旧操作不能落到新行。
- 同内容重复获取保留列表身份；译文和收藏只局部更新，保留滚动、跟随意图与选区。断句规则变化不改写旧收藏及已提交问答材料。
- 新学习句收藏 ID 在现有 `sentenceId` 组成项后追加原文范围 `[from, to]`，使共享时间、文字相同但来源位置不同的两句保持独立。范围来自 MAIN 已有连续原文坐标；前端收藏状态、后台写入、删除及重新载入共用这一身份。重复保存同一项不新增；不能通过改写原文、制造时间偏移或随机 ID 区分句子。
- 持久化 ID 在学习库往返时原样保留，不新增数据库迁移，不改变词汇语境的去重规则。旧格式 ID 保留；旧收藏的轨道、起点、文字仅匹配一个当前项时才关联其收藏状态，否则只保留在已保存列表中，不把一条旧记录关联到多个新项。操作已有记录时使用其实际 ID。

## 3. 译文

每条学习句使用完整原文送译，两处读取同一结果和实际来源。已有平台译文与完整原句可唯一对应时直接复用；只有片段译文或仅有时间重叠时，交给本视频选定的渠道翻译整条原文。

长学习句在播放器内可继续分屏。屏幕切点沿用源词段时间，缺失处在相邻锚点间估算。整句一次送译时可带上换屏标记；标记完整时播放器使用对应译文，侧栏展示连贯全文。只有纯文本译文可用时，按目标语言的标点和词界近似分屏。收藏、侧栏高亮与自动暂停仍绑定完整学习句。

翻译覆盖当前播放区间中的学习句、附近预取范围以及侧栏可见行。同一播放区间可有多条有独立译文的学习句。按原有批量限制调度，保留缓存、取消和过期响应隔离。视频、轨道、目标语言、断句结果或渠道变化时，旧译文不能覆盖新内容。
