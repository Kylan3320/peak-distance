# 技术边界

Peak Distance 使用 WXT、TypeScript 和 DOM/CSS，作为同一个 Manifest V3 扩展运行于桌面 Chrome／Edge。产品行为见 [PRD](PRD.md)，权限与对网页公开的资源见 [wxt.config.ts](../wxt.config.ts)。

## 多语言与本地学习库边界

- 网页、X 和视频各提供原文、语言、来源和定位，共用同一份学习数据。源语言和理解语言分别进入查询、缓存和记录身份；词典、常规译文、AI 词义及语境解释保留各自来源。行为见 [M11](specs/m11-multilingual-local-vault.md)。
- IndexedDB 承载活动库的运行数据、索引及待办。学习修改与待办在同一事务提交；换库在同一事务中归存旧库并恢复目标库。待办、偏好、共同基准与冲突按库隔离。断开连接保留库归属及待办；旧记录身份和已有凭据随增量迁移保留。
- 全局和文章词卡操作携带读取时的库身份，写事务校验归属。读回和同步回执校验记录／待办修订。其他入口的缺口见 [ROADMAP](ROADMAP.md#已复现缺陷)。
- 共享目录由受信任的扩展页面请求原目录权限。文件共享状态分别报告连接、当前权限和同步结果。目录中的 Markdown 与辅助元数据共同支持恢复；凭据、调用授权、配置和未发送编辑留在浏览器。
- 同步在当前 worker 串行。发布前核对共同基准和文件变化，发布后读回确认；跨浏览器和外部编辑器之间没有原子文件互斥。三方合并用共同基准判定冲突。记录组织、迁移和兼容边界见[集合与同步规格](specs/vault-collections-sync.md)。

## 当前文章学习与独立知识点

- 文章学习从已保存的词汇上下文按规范化来源派生。列表、预览和复习使用该来源的原句与解释；复习范围在启动时固定，视频已保存词汇复用同一机制。
- 知识点和翻译摘录保存来源及必要引文副本，从当时材料快照归属，使用现有事务、待办和共享集合。删除原聊天不影响知识点。已保存翻译允许关闭界面后回填，回填校验库、记录和编辑身份。见[文章学习](specs/current-content-learning.md)及[翻译收藏](specs/translation-learning.md)。

## 在线服务与问答

- 常规联网由后台发起，词典返回内容解析为纯数据。AI 调用由明确动作或有效模式授权；凭据仅由受信任的扩展上下文读取，自定义域名在保存时申请权限。请求固定服务、模型及来源，切换与取消后丢弃过期结果。
- 浏览器内置翻译在扩展 offscreen 文档和同源 iframe 运行，首次模型下载通过可见准备页的用户点击完成。Google 与内置渠道的缓存和收藏按实际来源分开。路由与缓存生命周期见[翻译学习规格](specs/translation-learning.md)。
- 问答的窗口临时编辑在 session 中，已提交历史在 IndexedDB。首次发送事务同时保存会话、材料、首问和回答占位；后续引用绑定原材料快照。材料与模型指令分离，来源链接取自有效快照。换库、关闭和切会话使过期编辑失效。

## YouTube 字幕

- MAIN world 复用有效的 timedtext 请求，按视频、轨道身份及代次确认来源。页面桥载荷对宿主脚本可见，双方校验消息方向、视频及请求代次。
- 同一轨道派生播放器短片段、侧栏学习句与播放区间。译文、收藏与选区绑定各自的原文和来源范围；播放与写入操作校验标签页、视频和字幕代次。断句、译文复用和定位见[学习句规格](specs/subtitle-sentence-units.md)。
- 视频收藏汇总按视频 ID 筛选词汇语境、整句和知识点，复用文章的词条聚合与侧栏列表。汇总从学习库刷新，字幕代次只用于字幕行操作。收藏中的时间链接按视频 ID 和已保存时间定位。
- 本视频翻译方式与逐句暂停按标签页保存在 session。通用设置与当前视频操作分离；当前视频操作经工作区直达绑定内容脚本。

## 工作区承载与选区翻译

- 原生侧栏与页内浮动 iframe 加载同一入口。页内外壳和学习控件使用 Shadow DOM；凭据表单运行在扩展源。对网页开放工作区、词典发音 iframe 和构建资源，消息按浏览器发送方校验归属。
- 模式移交先准备目标，成功后激活并停止旧容器写回。视图、复习和问答编辑按窗口恢复，显式关闭或匹配的承载页关闭清理临时编辑。浮动载入失败提供手动重试。全屏容器挂在全屏节点下，退出恢复原工作区；浏览器要求用户手势时提供侧栏恢复入口。
- 选区翻译走独立动作，完整输入进入缓存，收藏沿用知识点保存路径。词典发音 iframe 直接加载受支持的音频；词卡更新保留播放器，关闭或换源释放。选区和词卡通过带身份的关闭消息收口。

## 外观主题

主题保存在当前浏览器。扩展页与 Shadow Host 共用 tokens，按自己的根节点应用；宿主只更新扩展注入的词汇标记。外观变更走样式更新，保留正在使用的页面与任务状态。视觉规则见 [design.md](../design.md)。
