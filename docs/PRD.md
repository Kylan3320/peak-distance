# 产品约定

Peak Distance 是个人自用的桌面 Chrome / Edge 多语言学习扩展，覆盖普通网页 / X 与 YouTube 常规视频。原文用于学习，理解语言可按源语言设置。本文维护已确认的产品约定；交付状态、已知缺陷与当前任务见 [ROADMAP](ROADMAP.md)。多语言与学习库范围见 [M11 spec](specs/m11-multilingual-local-vault.md)，选区翻译及查询缓存修订见 [翻译学习规格](specs/translation-learning.md)。

## 核心行为

| 场景 | 约定 |
| --- | --- |
| 单词 / 固定短语 | 默认免 key，先按下述规则复用有效缓存；需要联网时适用词典优先，无词典结果时按设置使用免费译文或 AI 释义，结果类型和来源分别标明。短语匹配完整表达；可查看原文、收藏和解释语境 |
| 自由短语 / 句子 / 段落 | 选中后点击“翻译”，在可移动、可保持展开的就地浮层显示常规译文，并可收藏为独立知识点；主动翻译不依赖词典查询，不冒充词典释义 |
| 双语字幕 | 选择可用原文轨道；默认使用理解语言的已有字幕、平台翻译或免费翻译源。可切换常规 / AI，译文显隐与双语开关独立 |
| AI 解释 | 点击“解释语境”或明确选择 AI 后请求；另可主动开启查词未命中自动兜底，具体触发边界见 M11。悬停、标记和预取不调用 AI |
| 独立问答 | 随时新建对话；页面、选区、视频字幕为可选材料。切标签页不切当前会话，同一内容可以有多个会话 |
| 学习记录 | 保存表达、原句、结果及来源；视频附播放位置。刷新 / 重启后可恢复，查词或翻译失败不阻止收藏 |
| 再次遇见 | 网页和字幕共用 saved / learning / known；标记可关闭，动态正文更新后仍可识别 |
| 当前文章学习 | 在「当前内容」查看本篇主动保存的生词与独立知识点；按类别回顾、复习，不自动扫描全文匹配全局词库 |
| 原句复习 | 使用已存 saved / learning 词条与范围内原上下文；单语言练习，单词与释义分别揭示，支持前后切题、跳题与打乱顺序，可改状态、返回来源，不发 AI 请求 |

## 查询与调用

- 字典不要求账户或 key，不下载整套词库；缓存已查询的结果。网络不可用与查无词条分别呈现，不无限轮询。
- 默认查词先查适用词典缓存；AI 兜底关闭且未显式指定词典时，同条件有效 Google 译文缓存可直接返回。缓存未命中时按首选词典、备用词典及原有兜底联网；显式选择词典不被译文缓存短路。具体路由见 [翻译学习规格第 4 节](specs/translation-learning.md#4-请求语言与响应)。
- 选区翻译的源语言依次采用本卡手动选择、字幕轨道、选区元素继承的有效 `lang`、自动模式；不把启发式猜测视为明确语言；元素语言与解析目标同主语言时初始改用自动模式，防止错误跳过翻译。目标语言及检测结果处理按 [翻译学习规格第 4 节](specs/translation-learning.md#4-请求语言与响应)。
- 普通词典与文本译文缓存有固定有效期和容量上限，跨浏览器重启保留；过期、淘汰及手动清理不影响收藏，规则见 [翻译学习规格第 5 节](specs/translation-learning.md#5-查询缓存与连接实验)。
- 默认理解语言为简体中文，可按源语言覆盖，共用于词语、句段和字幕；内容语言可纠正，不因短词识别不确定而按英语保存。范围与路由见 M11。
- 默认查词给基础义项或标明来源的译文，语境解释按需展开。首屏保留表达与简明结果；词性、例句、发音等字段有对应来源才展示。
- 查询未完成时可先收藏；关闭已收藏或正在收藏的词卡后，本次基础查询仍回填原上下文。未收藏时关闭取消查询；实际查询失败保留原文，不编造释义。
- 常规字幕翻译失败仅显示“翻译暂不可用”，操作为“用 AI 翻译”“重试”。点击前无 AI 请求；同意只作用于当前视频，换视频恢复默认。
- 用户主动选择默认 AI 翻译模式后可持续使用该模式；已配置 key 本身不代表选择 AI。
- 服务凭据和供应商配置留在面板内设置视图；查词保留词典署名与原文链接，播放器不显示模型品牌。
- AI 服务支持 OpenAI 兼容、Anthropic 和 Gemini 原生接口。预设服务选择后只需 API Key；地址、模型和协议按需展开修改。配置按服务分别保存，显式保存后切换生效，旧 DeepSeek Key 保持可用。
- 服务切换后新问答使用新配置，已开始的生成保持原配置；当前视频的 AI 译文、失败状态和在途请求失效重取，常规字幕不受影响。
- 选区和查词快照固定；旧选区、视频、轨道或服务的返回结果不能覆盖当前内容。字幕查词沿用已有暂停 / 恢复规则。
- 开关控制显示与请求，不删除有效缓存。词典释义、普通译文、AI 词义与语境解释分别存储，不互相冒充。

## 学习数据

- saved 为已收藏，learning 为学习中，known 为已掌握。收藏默认 saved，重复收藏保持现有状态，用户操作才改变状态。
- 同一源语言的同一表达去重，新语境追加；不同语言同形词独立维护状态和词形。同一视频的不同位置分别保留。规范化与去重实现以代码为准。
- 词形优先来自词典原形 / 屈折信息；不自动合并派生词或歧义关联，不为了生成词形额外调用 AI。
- 列表与复习的原句、语境释义和一般释义参考都取自同一已保存上下文。缺少语境解释时可展示带类型及来源的一般词典／译文／AI 词义参考，不冒充当前原句的语境答案；均未保存时才显示缺失。
- 当前文章按表达聚合本篇保存的上下文，包含已掌握词，列表预览与复习均使用本文原句。全局状态共享，新增语境不自动改状态；本篇范围与语言筛选取交集。分类计数反映该交集，只在当前范围有可复习记录时显示复习入口；筛选无结果可清除筛选，不误报为尚未收藏。
- 复习在启动时固定来源、语言、类别与返回目标；刷新、再来一轮、切标签及面板移交不改变范围，退出返回启动入口。词汇沿用 M11 单语言约定，待确认语言独立；知识点先呈现保存的问题／标题，再揭示保存正文，不新增评分或排期。
- 文章学习的完整行为、数据生命周期与验收见 [当前文章学习与独立知识点](specs/current-content-learning.md)。

## 本地学习库

- 未连接文件夹仍可本机使用；连接后 Chrome / Edge 共用同一电脑上的学习目录，无额外常驻程序或云账户。
- Markdown 保存词汇、原句、字幕句子、个人笔记、学习状态、语言偏好和完整聊天／材料。Obsidian 可修改笔记与词条状态，切回浏览器或打开面板时读回。
- 生词本与句子各使用一个持续维护的 Markdown 文档，记录按稳定 ID 分节；AI 对话继续每会话一个文档。旧散文件合并后保留可恢复备份。词语／句子集合见 [学习库集合与同步](specs/vault-collections-sync.md)；独立知识点与主动收藏的翻译摘录共用 `知识点.md`，复用既有保存、读回、编辑、删除传播及换库归属。
- 共享文件夹连同辅助元数据可恢复已同步内容；Key、AI 调用授权、服务配置、草稿和缓存留在各浏览器。文件合同、并发、迁移与验收见 M11。

## 问答与材料

- 显示语言与解释语言独立；AI 问答使用发送时生效的显示语言，用户明确要求的回答语言优先。显示语言与界面切换规则见 [界面语言规范](specs/ui-i18n.md)。
- 问答正文优先占用空间；输入框通过上边缘调节大小，材料与低频详情按需展开，快捷提问只在首问前显示。
- Enter 发送，Shift+Enter 换行；保留 Ctrl/⌘+Enter 发送。输入法候选确认不发送，回答生成中不重复提交。
- 会话首次发送通过前置校验并提交后才持久化；已发送消息、使用的材料与引用、保留解释可恢复。空白新对话不进入历史，读取活动会话不自动补建。具体保存与删除边界见 [M10 spec](specs/m10-chat-and-popup-interactions.md)。
- 未发送输入、材料与引用修改只临时保留；新建／切换会话或明确关闭面板时丢弃。切换生词本、复习、设置、浏览器标签页及固定／浮动模式时保留临时内容。停止可取消生成；切模块或浏览器标签页不取消已开始的生成。
- 一次最多附加一份主要材料，引用作为焦点。移除材料只影响后续请求，历史引用保留原快照。
- X 只提取目标帖子；视频使用已有字幕，不读取画面或音频。普通文章提取不完整时标明实际范围。
- 普通材料使用全文背景；超长材料按明确片段范围问答。回答引用可回到原文，定位失败可查看保存的原文。
- 「保存知识点」从有可靠文章材料关联、非空且已完成或已停止的回答产生独立学习记录，保存前后可编辑标题与正文。归属取该回答生成时的材料快照；保存来源和必要引用原文副本，不依赖原聊天读取。重复保存同一回答返回已有记录，不覆盖编辑。
- 「标记回答」是聊天内回答标记，与独立知识点分别表达。删除对话不影响生词本及已保存知识点／引文副本；删除知识点只删除该记录，删除后主动重存原回答产生新记录。标记回答不覆盖词典释义。回答知识点的行为与验收见 [当前文章学习规格](specs/current-content-learning.md)。
- 删除当前会话后保留历史列表，内容回到未保存的新对话空态；删除使用列表行或当前对话更多菜单内的展开确认按钮；纯空态不显示无效删除入口。

## 工作区与设置

- 普通网页、X 和 YouTube 共用浏览器原生固定侧栏与页内浮动面板，可切换并保留当前模块、会话、草稿和学习状态；同时只显示一个活动主面板。
- 当前文章视图在现有「当前内容」内呈现标题、来源和「生词／知识点」切换，最近选区保留为临时操作区域；活动页面变化不改变已经开始的复习或独立 AI 会话。行为见 [当前文章学习规格](specs/current-content-learning.md)。
- 设置在当前面板内完成；首次连接学习目录／重新授权若受浏览器限制，可复用独立扩展设置页。不新增独立学习页；现有 options 地址保留兼容。
- 正式品牌为 Peak Distance；纸感、山峰标志、山海插画、配色和排版见 [design.md](../design.md)，字幕字体沿用现有实现。
- 具体导航、模式生命周期与验收见 [M8 spec](specs/m8-peak-distance-uiux.md)。

## YouTube 学习界面

- 普通 / 剧场模式在视频下方显示更易读的字幕；全屏保持原生视频全屏。学习入口放在底部控制区，可找到翻译方式、译文显隐、字号、AP 和设置。
- 悬停词语就地显示简明释义及快速标记，点击展开同一张词卡，再次点击收起。悬停暂停；仅恢复由插件造成且未被用户操作或 AP 接管的暂停。
- 工作区的当前视频视图包含字幕、全部词汇及次数 / 位置、已保存三个页签。全屏按需显示播放器内浮动面板，默认不展开；退出全屏恢复此前模式偏好与模块状态。
- 全屏字幕减少底板面积与不透明度，同时保证亮／暗画面可读；保留现有字体、字号选项和控制条避让。
- 支持独立收藏词语和整条字幕，默认显示本视频记录，可查看全部；已有词语原句复习继续使用，不新增句子 SRS。
- AP 默认关闭，可独立开启，以实际显示的字幕项为暂停单位。临时翻译方式在后台 worker 重启后保持一致，状态未恢复时不得静默切到 AI。

原有播放与学习交互见 [M7 spec](specs/m7-youtube-learning-workspace.md)；面板、设置入口与字幕背景变更以 [M8 spec](specs/m8-peak-distance-uiux.md) 为准。

## 范围之外

ASR、音频采集、账号 / 后端 / 云同步、本地词库与离线翻译模型、完整 SRS、联网搜索、跨内容自动记忆。
Anki、X thread、Netflix、Shorts / 直播和多材料问答在实际需要时另行排期。

2026-10-24 接入浏览器自带 Translator／Language Detector API，常规翻译默认使用浏览器内置翻译；已明确选择的 Google 来源保留。首次使用通过可见准备页下载浏览器管理的语言模型，之后面板关闭不影响已收藏任务完成；未收藏任务可取消。设备、语言或模型不可用时明确提示，不暗中转发到 Google 或 AI；Google 保留为手动备选。Chrome／Edge 英中翻译与生命周期实测范围见[翻译学习规格 8.6](specs/translation-learning.md#86-内置翻译接入与默认渠道2026-10-24)。扩展自行分发和维护离线模型仍不在范围内。
