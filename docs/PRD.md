# 产品约定

Peak Distance 是个人自用的桌面 Chrome / Edge 多语言学习扩展，覆盖普通网页 / X 与 YouTube 常规视频。原文用于学习，所有原文语言共用默认翻译与释义语言。本文维护已确认的产品约定。阶段目标与优先顺序见[路线图](ROADMAP.md)。多语言行为见[多语言规格](specs/m11-multilingual-local-vault.md)，选区翻译及查询缓存见 [翻译学习规格](specs/translation-learning.md)。

## 核心行为

在 HTTPS 文章或文档的正文中按 Alt+S 开启逐段翻译，再按一次恢复原文。点击侧栏设置「整页翻译」中的快捷键可直接录入新组合，按 Esc 取消。可在已有翻译设置中选择双语直显、磨砂译文、仅看译文，以及浏览器内置或 AI 渠道。默认先读原文，悬浮或聚焦本段的磨砂译文即可核对。仅看译文在原位置呈现，恢复原文使用同一开关。

| 场景 | 约定 |
| --- | --- |
| 单词 / 固定短语 | 默认免 key，先按下述规则复用有效缓存；需要联网时适用词典优先，无词典结果时按设置使用免费译文或 AI 释义，结果类型和来源分别标明。短语匹配完整表达；可查看原文、收藏和解释语境 |
| 自由短语 / 句子 / 段落 | 选中后点击「翻译」，在可移动、可保持展开的就地浮层显示译文，可收藏为独立知识点。新安装使用常规翻译，之后记住用户选择的渠道。见[翻译规格](specs/translation-learning.md) |
| 双语字幕 | 选择可用原文轨道；默认使用理解语言的已有字幕、平台翻译或免费翻译源。可切换常规 / AI，译文显隐与双语开关独立 |
| AI 解释 | 点击“解释语境”或明确选择 AI 后请求；另可主动开启查词未命中自动兜底，具体触发边界见 M11。悬停、标记和预取不调用 AI |
| 独立问答 | 随时新建对话；页面、选区、视频字幕为可选材料。切标签页不切当前会话，同一内容可以有多个会话 |
| 学习记录 | 保存表达、原句、结果及来源；视频附播放位置。刷新 / 重启后可恢复，查词或翻译失败不阻止收藏 |
| 再次遇见 | 网页和字幕统一标记已收藏词条；标记可关闭，动态正文更新后仍可识别 |
| 当前文章学习 | 在「当前内容」查看本篇主动保存的生词与独立知识点；按类别回顾、复习，不自动扫描全文匹配全局词库 |
| 原句复习 | 使用已收藏词条与范围内原上下文；单语言练习，单词与释义分别揭示，支持前后切题、跳题与打乱顺序，可改状态、返回来源，不发 AI 请求 |

## 查询与调用

- 词典查询免账户和 Key。默认首选剑桥英汉、备用有道，保留已保存的偏好。显式选择词典时查所选词典。词典故障与查无词条分别提示。 [查词与翻译路由](specs/translation-learning.md#4-请求语言与响应)
- 词语、句段和字幕共用翻译与释义语言。默认值及单次选择见[翻译规格](specs/translation-learning.md#4-请求语言与响应)。
- 普通查词和文本译文的缓存跨浏览器重启保留。清除或淘汰缓存不影响收藏。 [缓存规则](specs/translation-learning.md#5-查询缓存)
- 语言不确定的词条以「待确认」身份保存。 已保存词条的[语言纠正](ROADMAP.md#已确认未排期)尚待排期。
- 默认查词给基础义项或标明来源的译文，语境解释按需展开。首屏保留表达与简明结果；词性、例句、发音等字段有对应来源才展示。
- 查询未完成时可先收藏；关闭已收藏或正在收藏的词卡后，本次基础查询仍回填原上下文。未收藏时关闭取消查询；实际查询失败保留原文，不编造释义。
- 常规翻译自动选择服务并标明实际来源，规则见[自动路由](specs/translation-learning.md#自动路由)。
- 常规字幕翻译失败仅显示“翻译暂不可用”，操作为“用 AI 翻译”“重试”。点击前无 AI 请求；同意只作用于当前视频，换视频恢复默认。
- 用户主动选择默认 AI 翻译模式后可持续使用该模式；已配置 key 本身不代表选择 AI。
- 服务凭据和供应商配置留在面板设置视图。词典保留署名和原文链接，播放器不显示模型品牌。
- AI 服务支持 OpenAI 兼容、Anthropic 和 Gemini 接口。授权、切换和旧配置行为见[AI 服务规格](specs/m9-ai-services.md)。
- 选区和查词快照固定；旧选区、视频、轨道或服务的返回结果不能覆盖当前内容。字幕查词沿用已有暂停 / 恢复规则。
- 开关控制显示与请求，不删除有效缓存。词典释义、普通译文、AI 词义与语境解释分别存储，不互相冒充。

## 学习数据

- 收藏记录与复习选择分开呈现。网页和字幕查词卡的书签可收藏或取消当前原句，保留同词的其他原句、笔记和复习选择。取消最后一条原句后，词条仍可在生词本管理，直到再次收藏原句才恢复原文标记和原句复习资格。新词首次收藏默认参与复习；saved／旧 learning 参与复习，known 表示暂不复习。生词本和复习页提供针对整个词条的移出／重新加入复习操作。
- 同一源语言的同一表达去重，新语境追加；不同语言同形词独立维护状态和词形。同一视频的不同位置分别保留。规范化与去重实现以代码为准。
- 词形优先来自词典原形 / 屈折信息；不自动合并派生词或歧义关联，不为了生成词形额外调用 AI。
- 列表与复习的原句、语境释义和一般释义参考都取自同一已保存上下文。缺少语境解释时可展示带类型及来源的一般词典／译文／AI 词义参考，不冒充当前原句的语境答案；均未保存时才显示缺失。
- 当前文章和视频可按来源回看并复习已收藏内容。文章的范围、列表与复习规则见 [当前文章学习规格](specs/current-content-learning.md)。

## 本地学习库

- 未连接文件夹仍可本机使用；连接后 Chrome / Edge 共用同一电脑上的学习目录，无额外常驻程序或云账户。
- 收藏会同步到已连接的共享目录，Obsidian 可编辑笔记与词条状态。读写、恢复授权和兼容规则见[学习库规格](specs/vault-collections-sync.md)。
- 凭据、AI 调用授权、服务配置、草稿和缓存留在各浏览器。

## 问答与材料

- 问答使用与[界面语言规范](specs/ui-i18n.md)一致的回答语言。
- Enter 发送，Shift+Enter 换行；保留 Ctrl/⌘+Enter 发送。输入法候选确认不发送，回答生成中不重复提交。
- 问答支持独立会话。首次发送、临时编辑和删除行为见[会话规格](specs/m10-chat-and-popup-interactions.md#2-会话与临时编辑)。
- 用户可停止生成。切模块或浏览器标签页时，已开始的生成继续。
- 一次最多附加一份主要材料，引用作为焦点。移除材料只影响后续请求，历史引用保留原快照。
- X 只提取目标帖子；视频使用已有字幕，不读取画面或音频。普通文章提取不完整时标明实际范围。
- 普通材料使用全文背景；超长材料按明确片段范围问答。回答引用可回到原文，定位失败可查看保存的原文。
- 可将符合条件的回答保存为独立知识点，保留来源与可用引文。保存、编辑和去重见[文章学习规格](specs/current-content-learning.md#23-保存独立知识点)。
- 「标记回答」标记聊天内回答，标记保留在会话中。

## 工作区与设置

- 普通网页、X 和 YouTube 共用浏览器原生固定侧栏与页内浮动面板，可切换并保留当前模块、会话、草稿和学习状态；同时只显示一个活动主面板。
- 文件共享的目录选择与授权在独立设置标签页完成，其余设置仍可在侧栏内操作。
- 网页正文的选区浮条可以就地收起、在本页隐藏或限时暂停，侧栏设置可恢复显示。具体范围见[选区入口](specs/selection-chat-actions.md#选区入口)。
- 正式品牌为 Peak Distance，保留浏览器工具栏图标。视觉、排版和控件见[设计规范](DESIGN.md)。
- 提供经典与简约主题。新安装及升级后没有主题记录时使用经典，已有选择继续保留。主题保存在当前浏览器，重启和固定／浮动切换后恢复，换库不改变选择。
- 切换主题不丢草稿、材料、配置输入、选区、滚动、复习或播放状态，也不触发新的查询／翻译／AI 请求。外观主题在设置内选择，无需重开页面。
- 首次使用默认固定模式，主动切换后记住偏好。切换失败时仍可使用原面板，进行中的查询和问答继续。受限页面使用原生侧栏，浮动不可用时说明原因。

## YouTube 学习界面

- 普通 / 剧场模式在视频下方显示更易读的字幕；全屏保持原生视频全屏。播放器仅保留直接开关双语字幕的按钮，显示开启状态；学习面板从浏览器扩展按钮打开。
- 详细字幕设置集中在侧栏设置页。通用偏好包括默认翻译方式、双语开关、译文显隐和字号，沿用本浏览器保存范围；「当前视频」显示视频标题、原文轨道、本视频翻译方式和 AP，仅作用于绑定的视频，不修改全局默认。关闭再开启字幕保留已有选择和可复用结果。
- 字幕词语支持就地查词和收藏，暂停恢复见[播放交互规格](specs/m7-youtube-learning-workspace.md#暂停与恢复)。
- 当前视频默认打开「字幕」，「词语」显示字幕中的词次与位置，「已收藏」显示本视频收藏总数。收藏按生词、整句、知识点汇总，同一词条计一次，展开可查看和取消单条原句。整句和已保存的选区翻译纳入各自分类；有时间位置的记录可跳回视频。换轨、关闭字幕或字幕未就绪时仍可查看。
- 播放器英文跟源轨，长块整条显示，首屏不等断句。侧栏按学习句阅读，双方共用整句译文。中文可提前，播放器默认合计两行并可展开，侧栏始终显示全文。播放器字幕关闭时，侧栏仍可独立取轨、阅读和翻译。

- 逐句暂停默认关闭，具体暂停规则见[播放交互规格](specs/m7-youtube-learning-workspace.md#逐句暂停)。

全屏内的浮动面板默认收起，可主动打开。关闭工作区保持播放状态，退出全屏恢复此前模块与模式。浏览器限制自动重开侧栏时提供点击恢复入口。

## 范围之外

ASR、音频采集、账号 / 后端 / 云同步、本地词库与扩展自行分发的翻译模型、完整 SRS、联网搜索、跨内容自动记忆。
Anki、X thread、Netflix、Shorts / 直播和多材料问答在实际需要时另行排期。
