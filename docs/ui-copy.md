# 界面文案约定

本文保留 2026-10-12 界面整理中确认的命名、语义和写作决策。显示语言、切换与控件状态见 [界面语言规范](specs/ui-i18n.md)，视觉布局见 [design.md](../design.md)。

## 维护位置

具体标签、提示、错误和五语言译文只在 [shared/uiMessages.ts](../shared/uiMessages.ts) 维护；扩展清单文案在 [public/_locales](../public/_locales)。目录键可能沿用旧中文字符串，不代表界面最终显示的文案。

## 已确认约定

- 中文功能名 2–4 字，单条静态说明不超过 20 字；品牌、语言名和技术配置名称保留必要标识，沿用已确认的例外。
- 同一功能在侧栏、网页和视频中使用同一名称；动作写清结果。
- 收藏表达、保存配置、标记回答和删除对话是不同操作。「保留解释」是聊天内回答标记；「保存知识点」产生可独立编辑、复习和同步的学习记录，删除对话后仍保留；「删除知识点」只删除该独立记录。回答标记不写成保存，删除会话不写成清空；材料移除与焦点取消不暗示历史原文已删除。新增知识点语义已接入代码，行为及验收边界见 [当前执行 spec](specs/current-content-learning.md)，具体五语言文案仍由目录维护。
- 原文语言、解释语言、显示语言分别表示内容身份、释义／译文语言与界面语言，不能混用。
- 原文来源与词典原页按实际目标命名，不能把词典链接写成页面原句来源。词典、普通译文、AI 词义和原句解释按实际结果区分。
- 回答完成不增加重复完成提示；保留生成、停止及失败状态。失败反馈说明实际原因和可执行动作，成功反馈放在操作附近。

## 说明与低频信息

帮助文字只解释必要的作用、范围或费用。语言说明拆为短说明，语言规则按需展开；缓存放入更多设置；学习库文件格式与断开行为放入文件说明；AI 服务地址、连接方式与模型放入更多设置。删除重复的操作说明，保留“配置仅存当前浏览器”的边界。
