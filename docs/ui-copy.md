# 界面文案约定

本文维护界面命名、语义和写作决策。显示语言、切换与控件状态见 [界面语言规范](specs/ui-i18n.md)，视觉布局见 [design.md](../design.md)。

## 维护位置

具体标签、提示、错误和五语言译文只在 [shared/uiMessages.ts](../shared/uiMessages.ts) 维护；扩展清单文案在 [public/_locales](../public/_locales)。界面实际用词以目录译文为准。

## 已确认约定

- 中文功能名 2–4 字，单条静态说明不超过 20 字；品牌、语言名和技术配置名称保留必要标识，沿用已确认的例外。
- 同一功能在侧栏、网页和视频中使用同一名称；动作写清结果。
- 收藏表达、保存配置、标记回答和删除对话是不同操作。「标记回答」仅标记聊天内回答；「保存知识点」产生独立学习记录；「收藏翻译」保存选区摘录。知识点保存与删除行为见[文章学习规格](specs/current-content-learning.md)和[翻译学习规格](specs/translation-learning.md)。
- 图标的提示与可访问名称写明动作与当前状态；不把旁边的文字说明常驻显示。「只看本对话已标记回答」明确筛选范围。菜单选项、表单标签、来源类型、必要结果和危险确认继续使用文字。
- 外观字段为「外观主题」，选项为「简约」「经典」；不命名为新版／旧版，不暗示经典会恢复旧布局。
- 回答标记不写成保存，删除会话不写成清空；材料移除与焦点取消不暗示历史原文已删除。
- 原文语言、解释语言、显示语言分别表示内容身份、释义／译文语言与界面语言，不能混用。
- 原文来源与词典原页按实际目标命名，不能把词典链接写成页面原句来源。词典、普通译文、AI 词义和原句解释按实际结果区分。
- 回答完成不增加重复完成提示；保留生成、停止及失败状态。失败反馈说明实际原因和可执行动作，成功反馈放在操作附近。

## 说明与低频信息

设置文案写在相关字段或动作附近，说明输入范围、当前状态、结果或恢复步骤。
