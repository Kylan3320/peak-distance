# 界面文案约定

本文保留 2026-10-12 界面整理中确认的命名、语义和写作决策。显示语言、切换与控件状态见 [界面语言规范](specs/ui-i18n.md)，视觉布局见 [design.md](../design.md)。

## 维护位置

具体标签、提示、错误和五语言译文只在 [shared/uiMessages.ts](../shared/uiMessages.ts) 维护；扩展清单文案在 [public/_locales](../public/_locales)。目录键可能沿用旧中文字符串，不代表界面最终显示的文案。

## 已确认约定

- 中文功能名 2–4 字，单条静态说明不超过 20 字；品牌、语言名和技术配置名称保留必要标识，沿用已确认的例外。
- 同一功能在侧栏、网页和视频中使用同一名称；动作写清结果。
- 收藏表达、保存配置、标记回答和删除对话是不同操作。「标记回答」仅标记聊天内回答；「保存知识点」产生独立学习记录；「收藏翻译」保存选区摘录。知识点保存与删除行为见[文章学习规格](specs/current-content-learning.md)和[翻译学习规格](specs/translation-learning.md)。
- 翻译卡复制／收藏和问答顶栏使用图标，动作名称保留在提示与可访问名称中；「只看本对话已标记回答」明确筛选范围。笔记保存／取消使用勾选与关闭图标，保留对应提示及可访问名称；设置中的 AI 保存与密钥清除同样使用 SVG，保留动作提示及可访问名称；字段标签、其余表单操作与菜单选项沿用文字，错误就近说明。
- 回答标记不写成保存，删除会话不写成清空；材料移除与焦点取消不暗示历史原文已删除。
- 原文语言、解释语言、显示语言分别表示内容身份、释义／译文语言与界面语言，不能混用。
- 原文来源与词典原页按实际目标命名，不能把词典链接写成页面原句来源。词典、普通译文、AI 词义和原句解释按实际结果区分。
- 回答完成不增加重复完成提示；保留生成、停止及失败状态。失败反馈说明实际原因和可执行动作，成功反馈放在操作附近。

## 说明与低频信息

帮助文字只解释必要的作用、范围或费用。语言说明拆为短说明，语言规则按需展开；缓存放入更多设置；文件共享先说明保存到文件夹的用途，在文件说明中交代其他浏览器选择该文件夹的操作、文件格式与断开行为；AI 服务地址、连接方式与模型放入「模型与接口」。删除重复的操作说明，保留“配置仅存当前浏览器”的边界。
